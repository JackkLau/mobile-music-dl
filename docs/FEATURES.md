# 功能与使用

[返回项目首页](../README.md) · [文档导航](README.md)

本文说明听屿的使用方式、支持范围与数据处理。安装包见 [GitHub Releases](https://github.com/JackkLau/mobile-music-dl/releases/latest)。

## 使用与登录

1. 在“解析”粘贴链接或接收分享，匿名访问为默认模式。
2. 点播音轨，或选择条目加入下载队列；收藏夹“全选”只作用于已加载条目。
3. 在“我的”打开官方网页登录。登录流程会自动验证会话，经本机加密保存后显示“登录成功”和账号名称，再点“返回听屿”；失败可手动点“完成登录”重试。
4. 下载完成后在音乐库离线播放。删除本地音频需确认；退出账号保留音频文件。

首次下载可能申请通知权限；拒绝后仍可在应用内查看状态。下载队列支持取消、失败重试、可靠的强 ETag + Range 续传、进程中断后手动恢复。已下载文件命中不会重新访问 CDN。

登录 Cookie 仅发送至 B 站 API，不发送给短链或音频 CDN。会话使用 Android Keystore 加密存储；退出清除会话和私密列表。临时签名 URL 不写入音乐库。内容权限、失效账号和平台限制按真实返回处理。

## 链接与音频支持

- 支持 BV、av、桌面和移动视频链接、分 P、手机客户端分享文本、Markdown 链接、`b23.tv` 短链，以及具体收藏夹和显式分页。
- 解析会处理包裹标点、NBSP、零宽字符，保留有效查询值与百分号编码。短链只允许受信任 HTTPS 跳转；桌面、移动和短链最终共用 BV/分 P、取流参数及视频页 Referer，忽略 `vd_source` 等分享参数。
- AAC 识别覆盖 codec/MIME 变体和部分缺失元数据；已确认 AAC 优先，不明音频 MP4 须由实际媒体组件验证。主地址无效时可采用合规备用地址。
- 保留受信任 `mcdn.bilivideo.cn` 及子域的 HTTPS 4483；其他域名非标准端口拒绝。签名音频 URL 不重新拼装，CDN 不接收账号 Cookie。
- 最终检查真实 AAC 编码、完整长度/时长、非加密音轨，成功重封装后才发布 M4A。**没有任意格式转码、MP3/FLAC 导出、音源分离或视频下载。**

## 管理已有的本地音乐

- 使用同一正式签名覆盖升级到新版，原数据库、下载记录和音乐文件保留。不要卸载旧正式版来完成升级。
- 打开应用会查找当前已获准访问的 `Music/听屿/` 音频。“音乐库 → 扫描已下载音乐”可申请音频访问权限，找回旧安装或数据库中遗漏的文件；只扫描这个目录，不收集整部手机的音乐。
- “导入本地音频”打开系统文件选择器，可多选其他目录里的音频。文件继续留在原位置，不复制、不转码；需要保留系统提供的读取授权。本地格式以 Android 媒体组件实际可读取的音频为准，不改变网络下载仅支持兼容 AAC/M4A 的范围。
- 扫描和导入保留已有曲目信息并去重；支持标题/作者搜索、单曲或全部播放、播放队列和确认删除。权限被拒绝或文件暂时无法读取不会清空音乐库。
- 删除会移除手机上的实际文件；需要系统授权时再确认。取消或失败保留记录与播放队列，确认框显示错误供重试。仅本地条目不可用时提示重新导入，不向 B 站发起请求。

外部移动文件或撤回授权后，原 URI 可能失效；请重新导入可读取的文件。真机文件提供方、系统授权和升级验证范围见 [0.1.2 验证记录](LOCAL-MUSIC-VERIFICATION.md)。

## 歌名、歌词与手机封面

- 常见“歌手《歌名》”“歌手 - 歌名”等视频标题会整理为歌名与歌手；多分 P 优先使用各自标题，上传者不再冒充歌手。合集和不明确的标题保留，Live／翻唱／Remix 等版本信息不删除。这是标题整理，不是听音识曲。
- 在完整播放器点“编辑歌曲信息”可修正歌名、歌手，查看原视频标题和上传者。已下载的音乐同样适用，修改保存在听屿内，不改动音频文件。修改身份后清除旧歌词，避免错配。
- 播放页切到“歌词”，点击“联网查找”依次尝试网易云音乐公开页面接口和 [LRCLIB](https://lrclib.net/docs)；只发送歌名、歌手和时长，不发送 B 站 Cookie。自动匹配要求歌名、歌手一致，已知时长在 ±2 秒以内，网易结果必须唯一；没有可靠时长只显示纯文本。
- 多个发行版本或视频时长不同时，进入“歌词选项 → 选择歌词版本”，核对专辑与时长并明确选择后保存；不自动选择搜索第一项。无结果时可修正歌曲信息或导入文件。
- “导入歌词”支持 UTF-8 或带 BOM 的 UTF-16 LRC／TXT（最多 256 KB、3000 行）。已保存歌词离线可用；LRC 随播放进度高亮，手动翻看后点“回到当前”恢复跟随，点歌词跳到对应句。歌词选项可每次提前／延后 0.5 秒（范围 ±30 秒），校准离线保存；替换歌词时重置。TXT 显示全文，纯音乐单独提示。
- 视频横图不再作为专辑封面。默认是手机方形唱片封套；“更换封面”可选自己的图片（最多 12 MB，最长边缩至 1024，完整显示且保持方向）。“联网找封面”先查询网易云音乐，无匹配时尝试 QQ 音乐；标注来源和“专辑封面／歌手照片”，手动确认后保存本机。修改歌曲身份会清除联网匹配封面，保留手选图片。尚不提取音频内嵌封面。
- 播放进度、上一首／播放暂停／下一首、模式、前后 10 秒及队列固定在底部；封面信息和歌词在上方各自滚动，处理系统安全区。
- 网易和 QQ 使用公开网页端点，不是承诺长期稳定的开放 API。QQ 歌词端点在 0.1.4 验证时拒绝请求，未接入其歌词；豆瓣仅提供外部资料查询入口，不自动抓取。
- 原音频、URI、播放队列标识与数据库表结构保持兼容。封面和歌词私有保存；切歌不丢正在编辑的草稿，也不会把上一首的查询结果挂到下一首。外部文件的歌词时间轴是否适合具体视频版本仍需核对。

来源实测、当前验证范围与限制见 [0.1.4 歌词与播放器验收](LYRICS-PLAYER-VERIFICATION.md)。旧版见 [0.1.3 验证记录](SONG-DETAILS-VERIFICATION.md)。

网络错误、UA 对照与日志导出见 [网络调试](NETWORK-DEBUG.md)。
