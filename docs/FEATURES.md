# 功能与使用

[返回项目首页](../README.md) · [文档导航](README.md)

本文说明微乐的使用方式、支持范围与数据处理。安装包见 [GitHub Releases](https://github.com/JackkLau/mobile-music-dl/releases/latest)。

## 使用与登录

1. 在“解析 → 从一个链接开始”选择哔哩哔哩、网易云音乐或 QQ 音乐。粘贴分享文本或从平台分享至微乐时，会识别支持的链接。
2. 点播音轨，或选择条目加入下载队列；收藏夹“全选”只作用于已加载条目。
3. 在“我的 → 登录哔哩哔哩”打开扫码登录。用另一台已登录哔哩哔哩的设备扫码并确认。二维码过期时点“刷新二维码”。只有一部手机时，可切换到“网页登录”，在官方页面完成登录。两种方式都经过账号验证，在本机加密保存会话后显示账号名称，再点“返回微乐”。
4. 下载完成后在音乐库离线播放。删除本地音频需确认；退出账号保留音频文件。

下载页可重试失败、取消或中断的任务，也可移除记录和对应临时分片。进行中的任务可先取消再移除。移除已完成记录会保留音乐库与手机音频文件。解析页点“清除解析结果”可清空当前链接及结果。

首次下载可能申请通知权限；拒绝后仍可在应用内查看状态。下载队列支持取消、失败重试、可靠的强 ETag + Range 续传、进程中断后手动恢复。已下载文件命中不会重新访问 CDN。

登录 Cookie 仅发送至 B 站 API，不发送给短链或音频 CDN。会话使用 Android Keystore 加密存储；退出清除会话和私密列表。临时签名 URL 不写入音乐库。内容权限、失效账号和平台限制按真实返回处理。

## 应用更新

在“我的 → 应用更新”点“检查更新”可下载 GitHub 最新正式版 APK，匿名模式也可使用。从 0.1.12 起，点“保存安装包…”选择位置，再从系统文件管理器打开已保存的 APK。微乐在保存前复核文件大小、SHA-256、包名、版本和正式签名。若系统报毒，请取消安装并[核对样本与检测结果](APK-SECURITY.md)。

已是最新版时仍可下载同版 APK。使用调试版时可以另存正式包。0.1.6 及更早版本请先从 [GitHub Releases](https://github.com/JackkLau/mobile-music-dl/releases/latest) 下载正式 APK，覆盖升级后即可使用应用内入口。

## 链接与音频支持

### 网易云音乐与 QQ 音乐单曲

- 支持官方歌曲页、手机分享文本、Markdown 链接及跳回本站歌曲页的短链，例如网易云的 `music.163.com/m/song?id=…`、`163cn.tv` 和 QQ 音乐的 `y.qq.com/n/ryqq/songDetail/…`、`c6.y.qq.com/base/fcgi-bin/u`。使用歌曲编号匹配歌名、歌手和时长。
- 点“下载到手机”将单曲加入下载队列。网易云使用官方下载接口。QQ 音乐要求当前歌曲开放普通音质免费下载，并返回与歌曲匹配的完整文件。两者均只保存平台实际提供的完整 MP3，成功后可从音乐库离线播放。平台要求购买、仅提供试听、地区限制或未返回可用音源时，会显示失败原因，可前往官方歌曲页。
- 解析或下载遇到平台登录要求时，微乐会弹出“二维码登录”和“手机号快捷登录”。扫码使用另一台设备，手机号由官网验证；QQ 使用绑定 QQ 的手机号，可能需要 QQ 密码。完成登录后自动重新解析并下载原歌曲。点“暂不登录”会保留原链接或任务。会员、版权和地区限制以平台返回为准。两家平台各使用独立 WebView 配置，登录信息只随本站歌曲接口请求发送。再次打开对应账号页可清除该站登录。设备 WebView 需要支持独立配置，旧版本会显示提示。
- 这两个入口处理单曲。歌单、专辑与加密离线包暂不支持。歌曲的下载权限及可用格式由平台和账号决定。

### 哔哩哔哩

- 支持 BV、av、桌面和移动视频链接、分 P、手机客户端分享文本、Markdown 链接、`b23.tv` 与 `bili2233.cn` 短链，以及具体收藏夹和显式分页。
- 解析会处理包裹标点、NBSP、零宽字符及 `https\://` 形式的转义协议头，保留有效查询值与百分号编码。短链只允许受信任 HTTPS 跳转；桌面、移动和短链最终共用 BV/分 P、取流参数及视频页 Referer，忽略 `vd_source` 等分享参数。
- AAC 识别覆盖 codec/MIME 变体和部分缺失元数据；已确认 AAC 优先，不明音频 MP4 须由实际媒体组件验证。主地址无效时可采用合规备用地址。
- 保留受信任 `mcdn.bilivideo.cn` 及子域的 HTTPS 4483；其他域名非标准端口拒绝。签名音频 URL 不重新拼装，CDN 不接收账号 Cookie。
- 最终检查真实 AAC 编码、完整长度/时长、非加密音轨，成功重封装后才发布 M4A。B 站链路只输出 AAC/M4A。网易云和 QQ 音乐的 MP3 按原格式保存。

## 管理已有的本地音乐

- 微乐使用珊瑚橙红和暖白色微笑音符。桌面、启动页、通知、应用内和默认歌曲封面共用同一标识。
- 默认下载到 `Music/微乐/`。在“我的”或“下载”中打开“下载位置 → 选择文件夹”，在系统窗口中确认。之后开始的下载会写入所选位置；可随时点“恢复默认”。更换位置后，已下载歌曲仍在原处播放。
- 在“音乐库 → 扫描已下载音乐”可以找回默认目录、旧版目录和已选文件夹中的音频。自定义文件夹只扫描当前一层。原目录授权失效或存储卡暂时不可用时，可以重新授权或接入存储卡。
- “导入本地音频”打开系统文件选择器，可多选其他目录里的音频。文件继续留在原位置，不复制、不转码；需要保留系统提供的读取授权。本地格式以 Android 媒体组件实际可读取的音频为准，网络下载支持的音源格式见上方各平台说明。
- 扫描和导入保留已有曲目信息并去重；支持标题/作者搜索、单曲或全部播放、播放队列和确认删除。权限被拒绝或文件暂时无法读取不会清空音乐库。
- 删除会移除手机上的实际文件；需要系统授权时再确认。取消或失败保留记录与播放队列，确认框显示错误供重试。仅本地条目不可用时提示重新导入，不向 B 站发起请求。

外部移动文件或撤回授权后，原 URI 可能失效；请重新导入可读取的文件。真机文件提供方、系统授权和升级验证范围见 [0.1.2 验证记录](LOCAL-MUSIC-VERIFICATION.md)。

## 歌名、歌词与手机封面

- 常见“歌手《歌名》”“歌手 - 歌名”等视频标题会整理为歌名与歌手；多分 P 优先使用各自标题，上传者不再冒充歌手。合集和不明确的标题保留，Live／翻唱／Remix 等版本信息不删除。这是标题整理，不是听音识曲。
- 在完整播放器点“编辑歌曲信息”可修正歌名、歌手，查看原视频标题和上传者。已下载的音乐同样适用，修改保存在微乐内，不改动音频文件。修改身份后清除旧歌词，避免错配。
- 播放页切到“歌词”，点击“联网查找”依次尝试网易云音乐公开页面接口和 [LRCLIB](https://lrclib.net/docs)；只发送歌名、歌手和时长，不发送 B 站 Cookie。自动匹配要求歌名、歌手一致，已知时长在 ±2 秒以内，网易结果必须唯一；没有可靠时长只显示纯文本。
- 多个发行版本、视频时长不同或自动来源不可用时，自动打开“选择歌词版本”；也可从“歌词选项”进入。候选来自网易云音乐和 LRCLIB，各自最多 20 项，显示真实歌名、歌手、专辑、来源和时长。搜索阶段不以 ±2 秒淘汰版本，不自动选择搜索第一项。
- 候选页可单独修改搜索歌名、歌手，也可只用歌名搜索；搜索词不改写本地歌曲信息。修改搜索词后须重新搜索才能选取。明确确认后按该来源歌曲编号获取并离线保存；某个来源失败时保留其他来源的候选，并显示来源及 HTTP／业务错误码。全部来源失败与没有搜索结果分别提示。
- “导入歌词”支持 UTF-8 或带 BOM 的 UTF-16 LRC／TXT（最多 256 KB、3000 行）。已保存歌词离线可用；LRC 随播放进度高亮，手动翻看后点“回到当前”恢复跟随，点歌词跳到对应句。歌词选项可每次提前／延后 0.5 秒（范围 ±30 秒），校准离线保存；替换歌词时重置。TXT 显示全文，纯音乐单独提示。
- 视频横图不再作为专辑封面。默认是手机方形唱片封套；“更换封面”可选自己的图片（最多 12 MB，最长边缩至 1024，完整显示且保持方向）。“联网找封面”先查询网易云音乐，无匹配时尝试 QQ 音乐；标注来源和“专辑封面／歌手照片”，手动确认后保存本机。修改歌曲身份会清除联网匹配封面，保留手选图片。尚不提取音频内嵌封面。
- 播放进度、上一首／播放暂停／下一首、模式、前后 10 秒及队列固定在底部；封面信息和歌词在上方各自滚动，处理系统安全区。
- 网易和 QQ 使用公开网页端点，不是承诺长期稳定的开放 API。QQ 歌词端点在 0.1.4 验证时拒绝请求，未接入其歌词；豆瓣仅提供外部资料查询入口，不自动抓取。
- 原音频、URI、播放队列标识与数据库表结构保持兼容。封面和歌词私有保存；切歌不丢正在编辑的草稿，也不会把上一首的查询结果挂到下一首。外部文件的歌词时间轴是否适合具体视频版本仍需核对。

当前来源实测、验证范围与限制见 [0.1.5 验证记录](WEILE-0.1.5-VERIFICATION.md)；历史见 [0.1.4 歌词与播放器验收](LYRICS-PLAYER-VERIFICATION.md)。旧版见 [0.1.3 验证记录](SONG-DETAILS-VERIFICATION.md)。

网络错误、UA 对照与日志导出见 [网络调试](NETWORK-DEBUG.md)。
