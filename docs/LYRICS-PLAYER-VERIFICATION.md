界面延续听屿雾蓝唱片视觉。参考成熟播放器的逐行高亮、手动翻看后恢复跟随、时间校准、来源核对和固定主控；没有复制网易／QQ 品牌界面或把测试曲目加入产品歌库。

## 数据来源与实测

使用真实编译的 `MusicCatalogRepository`，没有模拟网络，也没有用硬编码歌曲 ID 代替搜索流程。仅记录元数据、歌词行数、状态与图片字节数，不保存或提交歌词正文、封面文件。

| 样本 | 实际结果 |
|---|---|
| 孤勇者／陈奕迅，256 秒 | 网易自动唯一匹配，78 个时间点；专辑图、歌手照片下载校验成功 |
| I Want to Live／Borislav Slavov，233.281 秒 | 自动因两个发行版本拒绝猜测；返回两个手动候选，明确选中版本后获取 43 个时间点；专辑图与歌手照片成功 |
| 晴天／周杰伦，269 秒 | 网易搜索无精确匹配；QQ 专辑图与歌手照片兜底成功。不能把直接查询已知 ID 成功算作搜索成功 |

网易图片实际返回 `image/jpg`，初次客户端拒绝；补该 MIME 别名后重新验证成功，仍要求官方白名单、图片魔数及真实解码。HTTP 80 的已知官方图片地址仅规范升级到 HTTPS 443，不跟随任意重定向。

- 网易使用第一方公开页面端点 `api/search/get/web`、`api/song/detail`、`api/song/lyric`、`api/artist/{id}`，没有找到正式开放 API 的稳定性承诺。[示例歌曲页面](https://music.163.com/song?id=1901371647)。
- QQ 使用公开搜索返回的专辑／艺人标识构建官方图片地址；歌词请求返回业务码 `-1310`，未接入或变换参数绕过。[示例专辑页面](https://y.qq.com/n/ryqq_v2/albumDetail/000MkMni19ClKG)。
- [LRCLIB 官方接口](https://lrclib.net/docs) 保留为第二歌词来源，标识客户端，处理 Retry-After，无 B 站 Cookie。
- 豆瓣旧 `/v2/music/search` 实测 404，网页只作为外部资料入口；[官方声明](https://www.douban.com/about/legal)限制未经许可的数据复用，因此没有实现自动抓取兜底。

请求均为用户明确触发、有限候选、独立无登录凭据客户端，支持取消、失败重试提示、限流与响应大小限制。歌词来源覆盖与准确同步是两回事：匹配成功不证明具体视频没有前奏、剪辑或不同演唱版本。

## 设备测试事故与入口修复

2026-10-30，9 项窄屏设备测试通过后，Gradle UTP 的清理阶段跨用户卸载了应用，导致模拟器原 user 0 的应用私有数据库、播放队列和设置被清除。这是本轮测试操作造成的数据损失，不能将测试通过写成原用户数据得到保留。

共享音频文件仍完好，已扫描恢复 1 首到音乐库并备份。原播放队列和设置没有备份，无法恢复。手机本轮未连接，因此未受这次事故影响。公共记录只保留恢复数量，不记录私人音频文件名。

已将 `scripts/check.sh --device` 和 `premium-ui.json` 的 UI 验证入口改为 `scripts/check-device.sh`。该脚本要求显式设备序列号和非零测试用户，在安装前及运行前核对当前用户；仅执行带 `--user` 的覆盖安装和直接 instrumentation，没有卸载、清应用数据或删除用户命令。运行日志必须包含非空 `OK (N tests)`，出现失败／崩溃标记、异常退出或缺少成功结果均返回失败。

建议后续只使用可丢弃的专用模拟器，并先保存快照或应用数据备份。**非零用户本身不保证完全隔离**：Android 应用代码在用户间共享，覆盖安装仍可能更新其他用户使用的版本，instrumentation 测试也会操作其可访问的数据。本脚本消除了此次触发事故的 UTP 自动卸载路径，不能承诺所有设备操作没有风险。

先人工切换到本次测试的临时用户，再填入真实值并运行；占位值会被脚本拒绝：

```bash
source .tooling/env.sh
bash scripts/check.sh
export TINGYU_TEST_DEVICE='<测试设备序列号>'
export TINGYU_TEST_USER='<已经切换的非零临时用户ID>'
TINGYU_TEST_CLASSES='app.tingyu.ui.PlayerBottomControlsTest' \
  TINGYU_TEST_SCREENSHOTS=true bash scripts/check-device.sh
```

横屏尺寸 2400×1080／540 dpi（约 711×320 dp）、1.5 倍字体下的 5 项固定控制回归通过；竖屏 1080×2400／540 dpi（宽 320 dp）、1.5 倍字体的同 5 项也通过。使用直接测试入口，运行后应用仍安装。
